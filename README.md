# Weekendje Weg 🇳🇱

A web app to find weekend activities in the Netherlands and calculate the budget.

## Features
- 40+ activities across the Netherlands (museums, nature, theme parks, sightseeing, seasonal events)
- Filters: category, city, indoor (rain plan), kid-friendly, free, max price, "available this month"
- Plan Saturday and Sunday, move items between days, edit prices, add your own activities
- Budget calculator: tickets, transport (NS train or car), food, overnight stay, buffer
- Compare against your budget and copy the plan as text

## Run
It's a single static file — open `index.html` in a browser, or enable GitHub Pages (Settings → Pages → deploy from `main`).

> Prices are approximate 2026 estimates. Always check the official site before booking.
